# Blind Spot Lab

The free companion website of the Blind Spot Lab YouTube channel: how the mind fools us.
An atlas of logical fallacies and cognitive biases, a daily puzzle, philosophy, short courses and interactive games.

Live: https://tahawi0.github.io/blindspotlab/

- `content/` — all site content (JSON)
- `build.py` — static site generator, writes `docs/` (served by GitHub Pages)
- `tools/cards.py` — share cards and app icons
