Fallacy

Appeal to Ignorance

You treat something as true because nobody has proven it false, or false because nobody has proven it true.

Where you'll meet it: Home and family Work and school Online and in the news

In real life

At home
“Nobody’s proven this house isn’t haunted, so it must be haunted.”
On social media
“Scientists haven’t been able to prove this remedy doesn’t work, so it works.”
At work
“Nobody has complained about the new system, so everyone must love it.” — Maybe people just don’t know where to complain.

How to spot it

If the only evidence is “nobody proved otherwise,” then we simply don’t know yet. Not knowing isn’t evidence for anything.

How to respond without a fight

“The fact that nobody’s disproven it means we don’t know yet — not that it’s true. Let’s wait for real evidence.”

Don't confuse it with: Absence of evidence after a serious search

If people searched carefully for something that should have shown up, and it didn’t, that’s reasonable evidence it isn’t there. The fallacy is when nobody looked in the first place.

Test yourself

"Nobody has ever proven these crystals don't have healing energy. So they must."

What's the trick here?

No one proving the opposite means we don't know. It doesn't mean the claim is true.

Sources

  • Walton, D. (1996). Arguments from Ignorance. Penn State Press.
