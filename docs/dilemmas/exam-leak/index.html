Dilemma

The Leaked Exam

The night before the exam, someone posts a photo in the class group chat that looks like the exam questions. Nobody's sure if it's real.

Do you open the photo?

How do philosophers see it?

Duty ethics
If the questions are real, using them is cheating, even if everyone else does it. What's right isn't decided by how many people are doing it.
Utilitarianism
If everyone saw the questions and you didn't, your ranking takes a hit. But if everyone thought this way, the whole exam would lose its value.
Note
Notice that “everyone's doing it” is the same appeal-to-popularity (bandwagon) fallacy you'll find in the Atlas. Spotting that doesn't settle the question by itself, but it's worth thinking twice.

There's no single right answer here. The point is knowing why you chose what you chose.
